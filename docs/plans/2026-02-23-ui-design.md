# Agora UI Design Document

**Date:** 2026-02-23
**Status:** Approved
**Reference:** x402scan.com (structural inspiration, not visual clone)

## Intent

**Who:** Developers and crypto-native users evaluating x402 endpoints. They're at a desk, comparing services, deciding which endpoints to integrate into AI agents or applications. Technical, time-pressed, scanning for trust signals.

**What they must do:** Search endpoints by description/schema/domain. Assess reliability. Compare pricing. Understand the network topology. Find trustworthy facilitators.

**Feel:** Network operations observatory — precise, alive, data-dense. Like looking into a live network through a monitoring console. Dark canvas where data points glow as signals.

## Domain Exploration

**Concepts:** Reliability scoring, network topology, facilitator trust, endpoint health pulses, payment flow trails, price discovery, uptime signals, coverage mapping across chains/assets.

**Color world:** The physical space is a network operations center — deep dark backgrounds where data points glow like signals on radar.

**Signature element:** "Reliability pulse" — each endpoint/facilitator carries a breathing glow indicating health state. Teal pulse = reliable. Amber = degraded. Dim/still = inactive. A living indicator, not a static badge.

**Defaults rejected:**
1. Generic metric cards (icon + big number + label) → Density-first data tables with inline sparklines and reliability as horizontal fill bars
2. Light mode dashboard → Dark mode primary — dark canvas makes data glow, matches observatory metaphor
3. Sidebar navigation → Top nav with search as hero element — search IS the primary action

## Token Architecture

### Palette

| Token | Value | Purpose |
|-------|-------|---------|
| `--void` | `hsl(220, 20%, 7%)` | Canvas — the deep network |
| `--void-elevated` | `hsl(220, 18%, 10%)` | Cards, raised surfaces |
| `--void-hover` | `hsl(220, 16%, 13%)` | Hover states, tertiary surfaces |
| `--signal` | `hsl(168, 80%, 50%)` | Teal — healthy/active/primary accent |
| `--signal-dim` | `hsl(168, 40%, 25%)` | Muted signal for backgrounds |
| `--caution` | `hsl(38, 85%, 55%)` | Amber — degraded reliability |
| `--failure` | `hsl(0, 60%, 55%)` | Muted coral — down/error |
| `--base-blue` | `hsl(222, 100%, 50%)` | BASE identity, used sparingly |
| `--ink-primary` | `hsl(220, 15%, 90%)` | Primary text |
| `--ink-secondary` | `hsl(220, 12%, 62%)` | Supporting text |
| `--ink-tertiary` | `hsl(220, 10%, 42%)` | Metadata, timestamps |
| `--ink-muted` | `hsl(220, 8%, 28%)` | Disabled, placeholder |
| `--border` | `hsla(220, 15%, 50%, 0.12)` | Standard separation |
| `--border-soft` | `hsla(220, 15%, 50%, 0.06)` | Subtle separation |
| `--border-focus` | `hsla(168, 80%, 50%, 0.5)` | Focus rings (signal-colored) |

### Depth Strategy

**Borders-only.** Dark backgrounds swallow shadows. Low-opacity hsla borders provide quiet structure that glows faintly against the void. Matches the observatory metaphor — edges of light in darkness.

### Surface Elevation

Three levels with ~3% lightness jumps:
- Level 0: `--void` (canvas)
- Level 1: `--void-elevated` (cards, panels, nav)
- Level 2: `--void-hover` (hover, active, dropdowns)

Minimal jumps so data points (colored text, signals, fill bars) are the brightest things on screen.

### Typography

| Role | Font | Weight | Tracking | Why |
|------|------|--------|----------|-----|
| Headlines | Inter | 600 | -0.02em | Geometric, engineered for UI density |
| Body/Labels | Inter | 400/500 | normal | Clean readability at small sizes |
| Data (URLs, hashes, prices) | JetBrains Mono | 400 | normal, tabular-nums | Developer tool — monospace for machine-readable data |

Inter because it's geometric and precise — built for interfaces, not personality. JetBrains Mono because the primary data type is URLs and addresses.

### Spacing

Base unit: **4px**. Scale: 4, 8, 12, 16, 24, 32, 48, 64.

4px allows tight data rows (32px row height) while 8px multiples give comfortable component padding. Dense but not cramped.

### Border Radius

Scale: 4px (inputs, buttons), 6px (cards, panels), 8px (modals, popovers). Sharp side — this is a technical tool, not a friendly consumer app.

## Layout

### Navigation

Top horizontal nav bar. No sidebar.

**Why:** Only 3-4 pages. Sidebar wastes horizontal space that data tables need — every pixel of width matters for URLs, schemas, payment details.

```
┌──────────────────────────────────────────────────────────────┐
│  [◉ Agora]     Endpoints  Facilitators  Network     [🔍]    │
├──────────────────────────────────────────────────────────────┤
│  Search bar (full-width, prominent on home)                  │
│  "Search endpoints by description, domain, or schema..."     │
├──────────────────────────────────────────────────────────────┤
│  Page content area (full-width)                              │
└──────────────────────────────────────────────────────────────┘
```

- Active page: `--signal` underline, not background change
- Inactive: `--ink-secondary`, active: `--ink-primary`
- Logo "Agora" in `--signal` teal
- Search icon in nav expands to full search on sub-pages

### Pages

1. **Endpoints** (home) — Searchable data table. Reliability scores, domains, pricing, freshness. The primary view.
2. **Facilitators** — Aggregated by domain. Health overview, endpoint count, reliability trend sparklines.
3. **Network** — Topology visualizations, distribution charts, crawl stats, EDA panels.

## Component Patterns

### Endpoints Table

Two-line dense rows. Leading reliability pulse as signature.

```
● domain.com/api/v1/translate    GET    $0.002/req   ████░ 87%
  "Translates text between languages"   Base  USDC   2h ago

◐ api.weather.io/forecast        GET    $0.001/req   ██░░░ 42%
  "Returns 7-day weather forecast"      Base  USDC   5d ago

○ service.xyz/generate           POST   $0.01/req    ░░░░░  0%
  "Generates images from text"          Base  ETH    14d ago
```

- **Reliability pulse:** ● (teal/filled = healthy), ◐ (amber/half = degraded), ○ (dim/empty = inactive)
- **URL** in JetBrains Mono, description below in Inter
- **Reliability bar** — horizontal fill, color shifts signal → caution → failure
- **Price** as $/request — the decision-relevant unit
- **"Last seen"** as relative time — freshness signal
- Inline filter chips: network, price range, reliability threshold, asset

### Facilitator Cards

```
┌─────────────────────────────────┐
│ ● coinbase.com                  │
│   12 endpoints · 99.2% uptime   │
│   ▁▂▃▄▅▆▇█▇▆  reliability 30d  │
│   Base · USDC, ETH              │
└─────────────────────────────────┘
```

- `--void-elevated` surface, `--border` edges
- Inline sparkline for reliability trend
- Pulse indicator matching table row signature

### Network View

- **Distribution charts:** Horizontal bars (not pie) — endpoints per network, per asset, per price bracket
- **Crawl stats:** Inline metrics, not card grid: `12,571 endpoints · 847 domains · 13 facilitators · last crawl 2h ago`
- **EDA panels:** Full-width chart areas with `--border-soft` separation

### Search

- Full-width input, `--void-elevated` background, `--border` edge
- Results filter the table live — no separate results page
- Filter chips below: network, price range, reliability threshold, asset type
