## Database

### Overview

Agora uses PostgreSQL 16 with the pgvector extension for semantic search.
The database runs in Docker on **port 5433** (not the default 5432) to avoid
conflicts with any locally installed PostgreSQL instance.

### Connection

- **User:** `agora`
- **Password:** `agora`
- **Database:** `agora`
- **Host:** `localhost:5433`
- **DSN:** `postgres://agora:agora@localhost:5433/agora?sslmode=disable`

### Core Tables

| Table | Description |
|-------|-------------|
| `endpoints` | x402 API endpoints discovered from Bazaar (URL, description, embedding vector) |
| `payment_options` | Payment methods accepted by each endpoint (network, token, facilitator) |
| `crawl_runs` | Metadata for each Bazaar crawl run (start/end time, pages, counts) |
| `transactions` | On-chain x402 payment transactions (V1 from CDP, V2 from Alchemy) |
| `facilitators` | Known facilitator wallet addresses with sync timestamps |

### Materialized Views

| View | Description |
|------|-------------|
| `endpoint_scores` | Reliability scores per endpoint (transaction count, volume, recency) |
| `discovered_sellers` | Seller addresses discovered from on-chain payment data |

These views are refreshed after each CDP sync run completes.

### Migrations

SQL migration files live in `migrations/`. They are embedded into the Go binary
via `migrations/embed.go` which exports `var FS embed.FS`. This pattern is
necessary because Go's `//go:embed` directive doesn't allow `../` paths — the
embed must live in the same directory as the files it references.

Run migrations with:
```bash
./agora.exe migrate
```

### pgvector

The `endpoints` table has a `description_embedding` column of type `vector(384)`.
This stores 384-dimensional vectors generated by the `all-MiniLM-L6-v2` model
via the embed sidecar. Semantic search uses cosine similarity (`<=>` operator)
to rank results against a query embedding.

### Quick Access

```bash
# One-off query
docker exec $(docker ps -q --filter ancestor=pgvector/pgvector:pg16) \
  psql -U agora -d agora -c "SELECT count(*) FROM endpoints;"

# Interactive session
docker exec -it $(docker ps -q --filter ancestor=pgvector/pgvector:pg16) \
  psql -U agora -d agora

# Useful queries
# SELECT count(*) FROM transactions;
# SELECT name, last_synced_at FROM facilitators;
# REFRESH MATERIALIZED VIEW endpoint_scores;
```

### Docker Compose

The `docker-compose.yml` (dev) starts just PostgreSQL.
The `docker-compose.prod.yml` starts the full stack including seed data loaded
on first boot. Both map the container's port 5432 to host port 5433.
