## x402 Protocol

### What Is x402?

x402 is a protocol that lets APIs charge per-request using stablecoins (USDC on Base).
When a client (AI agent or user) hits an x402-enabled endpoint, it gets back HTTP
`402 Payment Required` with payment details. The client signs a USDC authorization,
attaches it as a header, and re-sends the request. A facilitator submits the payment
on-chain and the API serves the response.

### Key Actors

- **Client/Agent** — The AI agent or user making API requests and signing payments.
- **Resource Server** — The API endpoint that charges for access via x402.
- **Facilitator** — A trusted intermediary that verifies payment signatures, submits
  them on-chain, and pays the gas fee. The facilitator wallet address is the key
  identifier for detecting x402 payments in on-chain data.

### Settlement Versions

#### V1: EIP-3009 (transferWithAuthorization) — ~95%+ of all x402 payments

The facilitator calls `transferWithAuthorization()` directly on the USDC contract.
This emits two events on-chain:
- `AuthorizationUsed(address authorizer, bytes32 nonce)`
- `Transfer(address from, address to, uint256 value)`

**Detection strategy:** A USDC Transfer event where `transaction_from` (the gas payer)
is a known facilitator wallet address is an x402 V1 payment. This is the approach
used by both x402scan and Agora.

#### V2: Permit2 Proxy Contracts — barely used as of early 2026

Uses dedicated proxy contracts that emit `Settled()` and `SettledWithPermit()` events:
- Exact proxy: `0x4020615294c913F045dc10f0a5cdEbd86c280001`
- Upto proxy: `0x4020633461b2895a48930Ff97eE8fCdE8E520002`
- PermitTransfer proxy: `0x4020CD856C882D5fb903D99CE35316A085Bb0001`

V2 has near-zero on-chain activity. The Agora V2 indexer (`internal/indexer/`) exists
for completeness but consistently finds 0 transactions.

### USDC on Base

- **Contract address:** `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`
- **Decimals:** 6 (1 USDC = 1,000,000 raw units)
- **Transfer event signature:** `Transfer(address,address,uint256)`

### Facilitator Registry

x402scan maintains a static list of ~20+ known facilitator wallet addresses in
their open-source repo (`packages/facilitators/`). Each entry includes: name,
wallet address, chain, and first transaction date. Agora stores these in the
`facilitators` table and syncs transactions per-facilitator.
